# 滤镜 · 薛仁雅档案

从仓库根目录启动静态服务器，访问 `/filters/`。筛选器默认不显示任何照片。可从本机上传或拖放图片，并保存 PNG。工具不调用模型、不上传图片。

- 长虹玻璃：全图或下半幅折射，点画面或用方向键移动清晰区。
- RGB 故障：调节强度和错帧密度，点击画面或按回车换一帧。
- 像素拖影：按住划动，实时绘制拖影；支持触摸、撤销和清空。
- CRT 监视器：青蓝调色、扫描线与从照片亮度计算的波形。
- 构成主义海报：方幅几何排版、半调网点和可编辑短标题。

「上传照片」只载入当前编辑器。「图库 → 添加照片」在本机浏览器存储图片，五个滤镜共享，可随时移除；浏览器不允许本地存储时，仅保留在当前页面。网站不预置公开样片，不读取 MUSE 的照片。
