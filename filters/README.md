# 滤镜 · 薛仁雅档案

静态目录；使用仓库根目录启动静态服务器，访问 `/filters/`。
当前仅保留长虹玻璃（Canvas 2D），有全图和下半幅两种范围。可选择或拖放本地图片，输出 PNG；图片不上传。无生成式 AI 和第三方运行时依赖。资源全部随站点发布。

## 示例图片与维护

默认示例是 K-POPIT 케이팝잇 的《钢铁少女团2》电台上班路画面（图 8），核对 YouTube 原视频为 Creative Commons Attribution，Commons 文件页标 CC BY 4.0；重新编码并删除元数据，缩略图和导出标注滤镜改动。点画面或用方向键可手动移动清晰区，不识别人脸。见 `image-rights.html#demo-photo`。

上一版可用备选：[Ten Asia BVLGARI 活动图](https://commons.wikimedia.org/wiki/File:Seol_In-ah_at_BVLGARI_photo_call_event.jpg)，复核为 CC BY 3.0，本版未收录。杂志、剧照、社媒按单图另查，不因公开或可嵌入而搬运。

效果参考与许可记录另见 `references.html`。示例资源本地托管，不由远端热链。

## 其他滤镜

- RGB 故障：调强度和错帧密度，点击预览换一帧；按回车也可操作。
- 像素拖影：按住划动实时出拖影，支持触摸、撤销、清空、调整拖影长度和画笔宽度。

两项都是浏览器内的像素算法，不上传本地图像。列表缩略图与原长虹玻璃封面同源，基于署名的 K-POPIT CC BY 4.0 示例进行滤镜处理。

- CRT 监视器：青蓝调色、扫描线、暗角及取自照片亮度的波形，叠加风格化监视器界面。
- 构成主义海报：方幅排版、红黑几何图形和从原图计算的半调网点，支持编辑短标题。

上述两项是独立的 Canvas 2D 实现，无需加载 Python 或第三方脚本。

图库从共享素材清单读取仅允许滤镜使用的样片；点击图片选用，点击标题查看对应 Instagram 原帖（如已记录）或实际原图来源。未获转载或二改许可的 IG 照片不进入滤镜选图。
