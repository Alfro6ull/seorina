# 滤镜 · 薛仁雅档案

从仓库根目录启动静态服务器，访问 `/filters/`。三个滤镜在同一工作台切换，窄屏横向滑动选择。切换保留原图，并为当前照片保留每项滤镜的参数。默认不显示任何照片。可从本机上传或拖放图片，用拖动分界线比对原图，并保存 PNG。工具不调用模型、不上传图片。

- RGB 故障：调节强度和错帧密度，点击画面或按回车换一帧。
- CRT 监视器：青蓝调色、扫描线与从照片亮度计算的波形。
- 构成主义海报：方幅几何排版、半调网点和可编辑短标题。

「上传照片」只载入当前编辑器。「图库」按页浏览站内公开图库，主动选择后才将该照片载入当前画布，并保留 IG 原帖入口。没有默认照片，不上传访客选择的文件。
