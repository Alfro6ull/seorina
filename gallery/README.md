# Seorina photo gallery

- `/gallery/`: the staggered, horizontal wall with column parallax, showing the full shared Gallery catalog. Only columns near the viewport mount images; photo links lead straight to the original Instagram post and carousel position. Reference: [Camille Mormal’s Portfolio 22](https://www.behance.net/gallery/156454485/Camille-Mormal-Portfolio-22).
- `/gallery/depth/`: the remaining photo study under Muse. Color sampled from the current photo lights a perspective room. Reference: [Atmospheric Depth Gallery, Houmahani Kane](https://github.com/houmahani/codrops-depth-gallery).

Independent HTML, CSS and JavaScript implementations. No code, photographs, video, branding or typefaces taken from the references.
